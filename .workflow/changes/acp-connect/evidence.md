# Evidence

Status: current, updated 2026-11-16

## Root cause

The `acp_*` commands were in `invoke_handler` (`desktop/src-tauri/src/main.rs`)
but missing from `build.rs` `commands()` and from
`capabilities/default.json`, so the ACL refused every `invoke('acp_*')`.
`acp_status` failing left `native` null, and the row's panel opened only on
`!!native`, so the stored error never showed.

## AC-1 — declared and granted

`build.rs` lists the five commands; `permissions/autogenerated/acp_*.toml`
are what tauri-build generates (a `cargo test` run leaves the tree clean);
`capabilities/default.json` grants `allow-acp-*`. `live-snapshot.json` and
`motion-render.json` are unchanged.

## AC-2 — the guard test

`main.rs` `command_permissions::every_command_is_declared_and_granted`.
`cargo test --locked` in `desktop/src-tauri`: 98 passed.

## AC-3, AC-4 — Connect always answers

`tests/acpAgentRow.test.tsx`: "shows Connecting while it waits, then the
refusal under the row when the shell has no status", "opens the row with
the error when connecting fails". `tests/acpAgents.test.ts`: the partial
refresh both ways.

## AC-5 — label per action

`src/components/LocalAcpAgent.tsx` tracks the waiting action (`pending`:
connect, signIn or other); every button is still disabled while one waits.
Test: "keeps Connect and Sign in as they are while Refresh waits".

## AC-6 — refresh error clears

The mount and focus refresh write `refreshError`, cleared on success; a
button press clears both. The row shows `error || refreshError`. Test:
"clears a failed refresh once a later one succeeds".
