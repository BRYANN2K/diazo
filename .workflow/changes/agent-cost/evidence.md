## Review remediation

Recorded 2026-11-17 on `feat/agent-scripts`, rebased onto `origin/dev` (22 commits on top after the second remediation round). `bun run typecheck`, `bunx oxlint --type-aware --deny-warnings`, `bunx eslint . --max-warnings 0` and `bun run format:check` exit clean; every test file below passes.

- Guide: `guideTopic('diazo-instructions')` returns the full `DOOP_GUIDE` again (38,789 characters); the script guide stays a `scripts` topic and is only injected when script tools are armed. `tests/scriptTools.test.ts`.
- Undo: `script_runs` stores `record` + `response` + `undo` (per-entity entries only — frames, tokens, components, compositions, token themes). No whole-canvas snapshot; read-only runs store no undo. The pre-image is captured lazily: each `mutate` keeps a projected copy per entity — strings and scalars by reference, only nested objects cloned — and compares by identity with a canonical-JSON fallback for object fields, so a write on a large canvas does not serialise every entity twice. `restoreScriptState` reverts entity by entity, leaves collaborator-changed entities in `unreverted`, and reports `reverted`/`reverted_partial`. `tests/scriptUndoPglite.test.ts` exercises save → JSONB round trip → revert on a real PGlite; `tests/scriptRunner.test.ts` asserts a scalar-only write never calls `canonicalJson`; canvas deletion cascades the rows (`server/db/persist.ts`).
- Retention: `pruneScriptRuns` keeps 30 days and at most 500 rows per canvas; `pruneToolCalls` keeps 30 days and at most 2,000 ledger rows per canvas, both swept hourly from `server/index.ts`. `tests/toolCallsRetention.test.ts` exercises both cuts on a real PGlite.
- Host limits: per-call argument cap (1 MB) refused in the worker before posting, a per-run argument total (8 MB) that kills the run, `frames.edit` ops cap (64), `search.*`/`libraries.search` limits clamped to fixed pages, token-name matching as substring or `*`-glob — guest input never reaches the regex engine (`^(a|a)*$` on a 26-char name returns immediately), a global semaphore of 4 QuickJS workers with a bounded wait queue (16, refused past it), a per-account run rate (30/minute), a `resourceLimits` heap bound on the worker thread, and kill-only-on-run-limits (`wall`, `memory`, `sdk_calls`, `frame_writes`, `script_size`, `result_size`, `args_bytes`) — renderer and search failures come back as ordinary SDK call errors. `tests/scriptSandbox.test.ts`, `tests/scriptWorkerOptions.test.ts`, `tests/scriptSdk.test.ts`, `tests/scriptLimits.test.ts`, `tests/scriptRunner.test.ts`.
- DOM: `frames.edit` inserts attributes before a self-closing `/>`; a `style` op keeps a data URL's `;base64` intact and refuses a value that smuggles a second declaration or braces; `replaceValues` walks parsed style attributes and `<style>` bodies only — never `data-style`, text nodes or script strings — skips custom-property declarations (no `var()` self-references) and masks `url()` bodies. `tests/scriptDom.test.ts` (one test per case).
- Post-run review: one rendered `checks.review` per changed frame runs after the guest script ends, outside its wall-time budget; lint-level reviews still answer every write during execution.
- Quality gate: the human ballot is a stratified random sample across all 12 briefs (not the first 24 pairs); the gate needs at least 24 human pairs in total and fails a kind the ballot never covered; model-vs-human disagreement is matched by `pairId` and presentation order on the whole sample; a judge returning one verdict on every pair is rejected as degenerate; `ingestHumanBallot` resolves Bryan's ballot through `blind-key.json` only; frame-count mismatch between paired runs aborts the pair. `tests/benchAgentCost.test.ts`, `tests/qualityRunner.test.ts`.
- Measures: `checks.measure` captures console errors via a listener installed before the frame document loads — `pageerror` (uncaught frame-script exceptions) lands as an error too — and font fallbacks are detected by width probes against the fallback stack instead of treating system families as missing. `tests/screenshotBounds.test.ts`.
- Final review screenshot: `shotTiles` cuts the frame into viewport-height tiles at scale 1, bounded to 8, each inside provider image limits — the previous unbounded `fullResolution` path is gone. `server/screenshot.ts`, `server/resident.ts`.
- Resident wiring: script tools and `SCRIPT_GUIDE` arm only when the task text asks for script mode; resident inputs go through the same zod schemas as MCP and `canvas_id` mismatches are refused; `timeout_ms` is accepted on `run_script` bounded to 1–60,000 ms.
- Bench honesty: the six transcripts are marked `"estimate": "hand-written"` and priced at `gpt-5.6-terra` (the OpenAI design-workhorse row added to `shared/modelPrices.ts`); `bench:agent-cost` prints its totals as estimates, never measured runs. No savings percentage is claimed anywhere as measured.
